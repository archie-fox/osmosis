# data/

These files are generated by `scripts/build-dict.mjs`. Do not edit them by hand. Run `node scripts/build-dict.mjs` to rebuild them.

| File | What it holds | Source | License |
|---|---|---|---|
| `cedict-*.tsv` | One line per simplified word: each reading in tone-mark pinyin, then one short English meaning | [CC-CEDICT](https://www.mdbg.net/chinese/dictionary?page=cc-cedict), published by MDBG | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) |
| `hsk.tsv` | One line per word: its HSK 2.0 level, 1-6 | [complete-hsk-vocabulary](https://github.com/drkameleon/complete-hsk-vocabulary) by Yanis Zafirópulos, `wordlists/exclusive/old` | MIT |
| `sources.json` | The file list, the source addresses, the CC-CEDICT release date, and the word counts | This project | MIT |

The `cedict-*.tsv` files are an adaptation of CC-CEDICT. They are shared under the same license, CC BY-SA 4.0. The code of this project is under the MIT License.

The `hsk.tsv` file is derived from complete-hsk-vocabulary. Its MIT license notice is in [LICENSE-hsk](LICENSE-hsk).
